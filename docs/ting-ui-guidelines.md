# Ting 界面约定

2026-11-10，用户确认：Ting 应有自己的轻量视觉风格，允许微调原版并同步到已有页面，不大幅改版。

- 延续 Meetily 的页面结构、Radix 交互和本地模型卡片。不要给新增 Provider 单独实现一套原生 HTML 下拉框、按钮或开关。
- 统一蓝色主操作与键盘焦点、浅色表面、清晰边框和适度圆角。颜色优先使用 globals.css 的语义变量；按钮、输入、开关、弹窗使用 components/ui，原有页面同时继承。
- 选中、已安装、处理中、不可用分别表达；不能只依赖颜色。异步操作显示具体动作，期间阻止重复提交，失败保留可重试输入。
- 动效轻且短，遵循减少动态效果偏好。不改动录音任务、凭据或 Provider 路由来实现视觉统一。
- 桌面界面暂统一英文。显示友好的模型名称；精确 API model ID 留在配置与诊断里。
- 本地实时模型与云端文件默认项分别说明。当前云端只支持文件，不能把选择云端页面解释成已经切换实时录音引擎。

本轮：重整 Alibaba Cloud 设置；共享主按钮/开关/焦点采用蓝色，菜单高亮采用浅蓝，弹窗遮罩减轻。增加加载、保存、测试、错误反馈和一次保存并测试；3.0 不展示已启用的方言保留开关。

验证：59 项前端测试、TypeScript 与生产构建通过；浏览器预览使用实际组件和模拟配置，检查下拉切换、保存/测试及共享弹窗。原生 Keychain 与实际云端导入仍需客户端验收。本轮未实现全站品牌替换或云端实时字幕。
