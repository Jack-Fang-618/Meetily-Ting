# Phase 1 稳定化记录 · 2026-11-10

## 本轮交付

- Whisper、Parakeet、Qwen/BuzzASR 共用 TranscriptionModelCard：原有蓝色选中边框、勾选、Ready 状态、下载/重试/取消、删除入口与当前模型说明。补充键盘可操作按钮及明确加载状态。
- 三类模型统一通过 select_transcription_model 加载并保存。加载或保存失败不提交前端选中状态、不显示成功；重复点击有防护。模型操作共用录音生命周期锁，录音、导入或重转录中拒绝切换/删除，繁忙操作立即返回而非排队后突然切换。
- 下载完成仅表示 Ready；点击卡片后才成为当前模型。删除当前模型前必须先选择其他模型，避免保存的配置指向已删除权重。Qwen 删除仅处理 Ting 专用目录，保留共享 Hugging Face 缓存。
- Qwen 准备支持取消，终止同一进程组的转换子进程；页面重开通过后台状态恢复准备提示。实际下载百分比未知时显示阶段提示，不伪造百分比。Qwen 1.7B、粤语 1.7B 和 BuzzASR 标记 Experimental。
- 上传窗口直接显示 Audio language / Model；未选择有效模型时不允许提交；已保存模型不可用时不静默切换至其他引擎。重转录同样检查选择有效性。
- 修复粤语微调模型强制覆盖 Auto/English 为 Cantonese。统一的输入限制配置应用于实时、导入和重新转录，详见 transcription-input-policy.md。
- 桌面脚本改为 tauri dev --no-watch，避免后台修改 Rust 源码自动重启录音应用。仍是开发启动方式，更新源码后需要手动重启，不等于已发布安装包。
- 之前的剪贴板、准备失败诊断和 LoRA generation config 修复保留并纳入此轮代码快照。

## 验证与边界

- TypeScript 检查；React/Bun 回归覆盖模型切换提交顺序、失败保留原选择、重复点击、Ready/下载/错误/取消及选择样式。
- Rust 全库单元测试覆盖音频处理、模型管理、导入、重转录和其他已有功能。两项原有设备测试调整为不依赖真实设备枚举结果、允许浮点 Duration 纳秒误差；未借此修改产品的设备检测逻辑。
- Python 输入分段及语言设置测试。
- 实际权重：Qwen3-ASR 0.6B、Qwen3 粤语 0.6B，分别测试英文、粤语、拼接混合音频、长音频、静音；使用合成公开内容，不使用私人会议。两者指定 English 时均保持英文输出。
- 实际 Parakeet Lightning：从 WAV 解码到统一推理入口的长音频测试；Qwen 原生 Rust/Python 进程协议测试。
- 未安装 Whisper 权重、Qwen 1.7B 或 BuzzASR，不额外下载。Whisper 本轮为代码与模拟输入回归，不能宣称其所有权重均通过实机验证。
- 混合音频为合成拼接测试；非准确率排名，未证明复杂现场录音的识别质量。
- 当前计算机控制工具无法绑定未打包的 Ting Dev 原生窗口。组件测试和编译/启动检查不能替代完整原生 GUI 点击验收，不将其记为已通过。
- 本轮未接云端、说话人识别或智能校订。实时大段结果仍沿用外层 VAD 时间戳，不包含逐词对齐；会后可重转录，失败片段不会自动回填已有记录。

## 后续每个 Provider 的完成标准

登记输入限制及语言能力 → 复用统一模型卡片与选择命令 → 验证安装/准备、加载、失败重试、取消和删除 → 语言/静音/短尾段/超长输入回归 → 原有 Provider 回归 → 实机音频及原生界面验收 → 保存 Git 检查点。模型转换成功或单次非空输出不单独构成稳定性验收。
